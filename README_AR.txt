مشروع أولي لتطبيق FlixNow TV على Android TV / Google TV

مهم:
- هذا مشروع مصدر أولي وليس ملف APK جاهزاً.
- يفتح الموقع داخل WebView بملء الشاشة ويدعم الرجوع بالريموت.
- لم يتم التحقق من توافق الموقع أو تشغيل الفيديو على Google TV.
- خيارات تغيير السيرفر والدبلجة لا يمكن إضافتها بشكل مضمون إلا إذا كانت صفحة المشاهدة أو مشغل الموقع يوفران هذه الخيارات/المسارات. هذا القالب لا يضيفها من تلقاء نفسه.

لإنشاء APK:
1) افتح Android Studio على كمبيوتر.
2) اختر Open ثم مجلد FlixNowTV.
3) انتظر Gradle Sync.
4) من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) ستجد APK داخل app/build/outputs/apk/debug/.

يتطلب بناء المشروع Android Studio حديثاً واتصالاً لتنزيل أدوات Gradle و Android SDK.
